# Employee Advance Calculator

## Project Overview
The Employee Advance Calculator is a frontend web application developed during my internship at Maruti. The application is designed to simplify and streamline the process of calculating employee advance amounts based on the required inputs and predefined calculation rules.
The project focuses on providing a simple, user-friendly, and efficient interface for entering employee details and generating advance calculations.

## Objective
The main objective of this project was to develop a frontend interface that makes the employee advance calculation process faster, easier, and less prone to manual calculation errors.
